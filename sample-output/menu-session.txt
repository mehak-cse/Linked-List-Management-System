==================================================
     SINGLY vs DOUBLY LINKED LIST - COMPARISON
==================================================
Feature                    Singly Linked List     Doubly Linked List    
--------------------------------------------------------------------
Links in each node         next only              prev and next         
References kept by list    head                   head and tail         
Memory per node            Less                   More (extra prev)     
Traversal direction        Forward only           Forward and backward  
Insert at Beginning        O(1)                   O(1)                  
Insert at End              O(n)                   O(1) using tail       
Delete from Beginning      O(1)                   O(1)                  
Delete from End            O(n)                   O(1) using tail       
Search / Count / Display   O(n)                   O(n)                  
Reverse                    3 refs: prev/curr/next Swap prev and next    
Bubble Sort                O(n^2)                 O(n^2)                
Remove Duplicates          O(n^2)                 O(n^2)                
Coding difficulty          Simpler                More links to update  

Summary: A Singly Linked List is simple and uses less memory.
A Doubly Linked List uses more memory but allows backward
traversal and fast insertion/deletion at the end.
